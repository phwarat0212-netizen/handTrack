# 🖐️ HandTrack - เว็บวาดรูปกลางอากาศด้วยนิ้วมือ

เว็บไซต์สำหรับวาดรูปบนหน้าจอโดยใช้กล้องเว็บแคมและนิ้วชี้ของคุณ ลากเส้นเขียนภาพกลางอากาศได้ง่ายๆ โดยไม่ต้องสัมผัสหน้าจอคอมพิวเตอร์หรือแป้นพิมพ์

## ⭐ ฟังก์ชันเด่น (เข้าใจง่าย)

* 🎨 **วาดรูปด้วยนิ้วชี้:** ชูนิ้วชี้ขึ้นตรงเพื่อลากเส้นวาดรูปบนจอ และพับนิ้วลงเพื่อหยุดวาด
* 🦴 **แสดงเส้นกระดูกมือ:** มีเส้นโครงสีฟ้านีออนและจุดวงกลมสีขาววิ่งตามตำแหน่งนิ้วและข้อมือจริงของคุณบนหน้าจอแบบสดๆ
* 📈 **ลายเส้นนิ่งและเรียบเนียน:** อัปเกรดระบบช่วยกรองอาการมือสั่น ทำให้ลากเส้นได้โค้งมน นิ่งสนิท และตอบสนองนิ้วมือของคุณได้ทันทีแบบไม่หน่วง
* 🗑️ **ชี้เลือกสีและลบกระดานได้:** ชูนิ้วชี้ค้างไว้ที่เมนูสีด้านบนเพื่อเปลี่ยนสี หรือชี้ค้างที่รูปถังขยะค้างไว้ 1 วินาทีเพื่อลบภาพวาดทั้งหมดออก
* ⚡ **ทำงานลื่นไหลไม่กระตุก:** ปรับจูนระบบประมวลผลให้ทำงานลื่นสมูท 60 FPS โดยไม่กินสเปกเครื่องคอมพิวเตอร์และไม่ทำให้เครื่องร้อน

## 🎮 วิธีการเล่นใช้งาน

1. เปิดเข้าใช้งานลิงก์ **[เข้าเล่นที่นี่](https://phwarat0212-netizen.github.io/handTrack/)**
2. กดปุ่มสีดำตรงกลาง **"Start Drawing"** และอนุญาตให้เว็บเข้าใช้งานกล้องเว็บแคม
3. **การสั่งงานด้วยมือ:**
   * **การวาดรูป:** ชูนิ้วชี้ขึ้นตรงเพียงนิ้วเดียว (พับนิ้วอื่นเก็บไว้) แล้วขยับนิ้วชี้เพื่อลากเส้นวาดภาพบนจอ
   * **การหยุดวาด:** พับนิ้วชี้เก็บ หรือลดมือลงจากหน้าจอ
   * **การเปลี่ยนสี / ลบกระดาน:** ชี้ปลายนิ้วไปค้างไว้ที่วงกลมสีด้านบน หรือรูปถังขยะค้างไว้สักครู่ วงกลมจะโหลดเต็มและทำงานตามสั่งให้ทันที
